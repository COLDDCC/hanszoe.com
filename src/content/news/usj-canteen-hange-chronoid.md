本条是韩吉以「实体形象」出现在官方线下场景的少见记录：USJ 用克罗诺人偶（クロノイド）做了韩吉，并与利威尔一起设为店内合影点。

## 官方说明

> 店内では、「リヴァイ」と「**ハンジ**」のクロノイド※と一緒に写真が撮れるフォトオポチュニティ（有料。指定メニューを注文することで体験可能）も開催します。
>
> ※皮膚やまなざし、髪の1本に至るまで徹底的に再現された人型の総称

关于食堂本身，官方另写：

> 立体機動装置や調査兵団のリュック、衣類などが無造作に置かれ、徹底的にクオリティを追求した食堂内では、劇中で使用されている楽曲に加え、あのキャラクターたちの会話も聞こえてきます。

## 官方概要

| 项目 | 官方内容 |
| --- | --- |
| 活动总称 | ユニバーサル・クールジャパン2020 |
| 会期 | 2020 年 1 月 21 日（火）～6 月 28 日（日） |
| 设施① | 「進撃の巨人 ＸＲライド」／スペース・ファンタジー・ザ・ライド（コースター形式、史上初の XR ライド） |
| 设施② | 「進撃の巨人 調査兵団の食堂」／ロストワールド・レストラン（作品史上初の主题餐厅） |
| 韩吉相关 | リヴァイ・ハンジ的クロノイド合影（有料，需点指定菜单） |
| 菜单方向 | 原作料理的复刻盘、以作品中「契约之苹果」为意象的甜点 |
| 同期周边 | 胸口エンブレム刺绣升级的调查兵团ジャケット、实寸大立体机动装置、调查兵团マント |

## 与韩吉档案的关联

官方在本篇点名的合影克罗诺人偶只有利威尔与韩吉两位，未说明选择理由，也未说明场内是否另有其他角色人偶；这是韩吉在官方线下活动中被实体化的记录。

**待核实**：官方未说明合影的具体收费金额与指定菜单名称；食堂内「あのキャラクターたちの会話」是否包含韩吉台词，本篇只写「会听到角色对话」，未列名单；该会期早已结束，USJ 页面链接为 http 协议，本次核实未确认其当前可访问性。
