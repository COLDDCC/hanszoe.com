| 赏位原文 | 尺寸（官方） |

| 超大吉04 選べるBIGマフラータオル【ハンジ】 | 约 1100×200mm |
| 大吉04 アクリルスタンド【ハンジ】 | 约 130×100mm |
| 中吉04 アクリルキーホルダー【ハンジA】 | 约 60×60mm |
| 中吉08 アクリルキーホルダー【ハンジB】 | 约 60×60mm |
| 小吉04 缶バッジ【ハンジA】 | 约 Φ56mm |
| 小吉08 缶バッジ【ハンジB】 | 约 Φ56mm |
